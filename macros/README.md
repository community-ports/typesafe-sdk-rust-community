# typesafeai-sdk-community-macros

Derive macros for [`typesafeai-sdk-community`](https://crates.io/crates/typesafeai-sdk-community):
`ChoiceLabels`, `ScoreLevels`, and `Questions`.

Use them through the main crate, which re-exports them under its default `derive` feature.
There is no reason to depend on this crate directly.
